ProfeYa.app

Descripción del proyecto

ProfeYa.app es una plataforma web creada para conectar estudiantes con profesores particulares de distintas materias y niveles educativos.

El objetivo del proyecto es facilitar la búsqueda de docentes de manera rápida y organizada, permitiendo que los estudiantes encuentren apoyo académico tanto en clases virtuales como presenciales.

Los principales usuarios de la plataforma son:

* Estudiantes
* Profesores particulares
* Personas que necesitan apoyo académico

Funcionalidades actuales

* Landing principal
* Navegación entre páginas
* Diseño responsive
* Registro e inicio de sesión
* Búsqueda de profesores
* Interfaz moderna e intuitiva

Tecnologías utilizadas

* CSS3
* JavaScript
