🐾 PetSitter

📖 Descripción del proyecto

PetSitter es una aplicación web creada para facilitar el contacto entre personas que necesitan cuidado para sus mascotas y usuarios que ofrecen ese servicio.

La plataforma intenta solucionar el problema de encontrar cuidadores confiables y disponibles para mascotas cuando sus dueños trabajan, viajan o no pueden ocuparse de ellas por un tiempo.

Los principales usuarios de la plataforma son:

* Dueños de mascotas
* Cuidadores y paseadores
* Personas interesadas en ofrecer servicios para animales

Funcionalidades actuales

* Página principal (Landing Page)

* Interfaz simple y moderna
